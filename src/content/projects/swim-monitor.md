Uisce brings squad management, training sessions, attendance, results and performance tracking into one swimming-club platform.

I designed the React interface, JSON:API backend and multi-schema PostgreSQL model. Redis supports the application, and Vitest covers client and API workflows, including more than 90 backend tests for workflows and data access.
