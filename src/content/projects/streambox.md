---

The Java server discovers local MP4 files, implements byte-range and HEAD responses, and streams through a bounded buffer so browsers can seek. The browser interface keeps watchlists and playback progress in local storage.

Streambox is a single-viewer local prototype, with no accounts, transcoding or licensed catalogue. Its sample film is generated media.
